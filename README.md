# AERIS

Лендинг консалтинга по **ИИ-автоматизации и системной архитектуре бизнеса**.

Сайт продаёт одну услугу: встроить ИИ и процессы в компанию клиента, снять рутину и вернуть время на рост. Входная оферта — **бесплатный аудит процессов за 48 часов**. Заявки сразу падают в Google Таблицу и на почту владельца.

Стиль: Warm Tech Minimalism, 2026. Овсяный фон, графит, лаванда и мята. Шрифты Unbounded и Inter. Визуалы — собственные 3D-стёкла, без стоковых фото.

---

## Для кого этот продукт

Собственники и топы малого и среднего бизнеса, которые:

- сами закрывают операционку вместо стратегии;
- собирают отчёты вручную из нескольких систем;
- теряют клиентов на стыке отделов и CRM;
- хотят внедрить ИИ, но не «чат-бота ради галочки».

Обещание на первом экране: до **40 часов в неделю** обратно команде. Первый шаг — диагностика, без шаблонного отчёта.

## Что продаём на сайте

| Блок | Задача |
|---|---|
| Герой | Остановить скролл, назвать боль, дать два действия: калькулятор эффекта и кейсы |
| Боль | Показать цену хаоса: рутина топов, ошибки между отделами, потолок роста |
| Решение | 4 шага продукта: нейро-аудит → архитектура ИИ → интеграция → обучение |
| Цифры | Социальное доказательство: конверсия ×3.5, рутина −40%, окупаемость 14 дней |
| Процесс | Как выглядит работа от бесплатной диагностики до передачи ключей |
| FAQ | Снять возражения: «у нас специфика», «дорого», «сотрудники саботируют» |
| Форма | Собрать лид: имя, телефон или Telegram, задача |

Дополнительно:

- калькулятор экономии на рутине (модальное окно);
- три кейса (модальное окно);
- страница [политики конфиденциальности](privacy.html);
- страница [отчёта](report.html) как лид-магнит к цифрам.

## Как устроена воронка

```
Посетитель
    → лендинг
    → форма «Забрать бесплатную диагностику»
    → параллельно:
         • строка в Google Таблице «AERIS Заявки»
         • письмо на ...@gmail.com
    → ответ в течение 48 часов, аудит
```

Таблица (аккаунт владельца): [AERIS Заявки]

Лист **Заявки**: дата, имя, телефон / Telegram, задача, источник.
